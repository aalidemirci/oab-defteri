# PyQtWebEngine GPLv3'tür; GPLv3 dağıtılan bütüne EK KISITLAMA konmasını
# yasaklar, bu ürünün lisansı (PolyForm Noncommercial) ise ticari kullanımı

# DİNAMİK bağlandığı ve kullanıcı kendi sürümüyle değiştirebildiği sürece

# karşılanması: packaging/README.md → "Lisans: PySide6 LGPLv3".

# qtpy NEDEN AYRI PİNLENİR: pywebview'ın Qt arka ucu bağlayıcıyı doğrudan
# seçmez, `qtpy` üzerinden gider (`webview/platforms/qt.py:23-37` —
# `from qtpy import QtCore`, `from qtpy import PYQT6, PYSIDE6`) ve pywebview

# `pyside6 = ["QtPy", "PySide6"]`). qtpy pywebview'ın Linux bağımlılığı

# geçer), bu yüzden burada açıkça pinlenir; yoksa Qt arka ucu hiç import

# (`desktop/tray.py::load_qt`).

# SÜRÜM TAVANI 6.8.x — Pardus 21 (Debian 11 / bullseye) kapısı: PySide6

# uçtan uca doğrulandı (23.09.2026). Sürüm yükseltmeden önce şu denetlenir:
#   nm -D --undefined-only .../libQt6WebEngineCore.so.6 | grep gbm_bo_get_fd_for_plane
